IMAGIE CREATION — FICHIERS MANQUANTS POUR GITHUB

Ce ZIP est un PATCH, pas le projet complet. Il contient les dossiers et fichiers qui manquent dans le repository GitHub vérifié.

IMPORTANT
- Décompressez ce ZIP avant de l’envoyer sur GitHub.
- Ne téléversez PAS le fichier ZIP lui-même dans le repository : GitHub ne le décompressera pas automatiquement.
- Gardez exactement les chemins des dossiers (site/assets, supabase/migrations, etc.).
- Ne créez PAS de fichier .env.local et ne publiez jamais de clé secrète/service_role.

FICHIERS INCLUS
- site/assets/* : CSS, JavaScript et modules utilisés par les pages du site.
- site/.env.example : modèle des variables publiques à configurer dans Vercel.
- supabase/migrations/002_account_profile_adult.sql
- supabase/migrations/003_email_otp_and_push_notifications.sql
- supabase/functions/verify-turnstile/index.ts
- supabase/templates/* : modèles HTML des e-mails.

COMMENT LES AJOUTER
1. Ouvrez le repository : https://github.com/brunaljeanralph-art/IMAGIE-CR-ATION
2. Vérifiez que vous êtes sur la branche main.
3. Cliquez Add file > Upload files.
4. Depuis l’ordinateur, faites glisser les dossiers site et supabase extraits dans la zone d’envoi. Le navigateur doit conserver les sous-dossiers.
5. Si les dossiers ne sont pas conservés, faites l’envoi par lots : entrez dans le dossier cible du repository, puis envoyez les fichiers de ce dossier.
6. Mettez le message : Restore missing IMAGIE assets and Supabase setup files.
7. Choisissez Commit directly to the main branch puis Commit changes.
8. Vérifiez ensuite que site/assets/app.css, site/assets/app.js, site/assets/auth-pages.js, supabase/migrations/002_account_profile_adult.sql et supabase/migrations/003_email_otp_and_push_notifications.sql apparaissent dans GitHub.

APRÈS L’UPLOAD
- Dans Vercel, conservez Root Directory = site.
- Le fichier .env.example est seulement un modèle : il ne connecte pas Supabase. Les vraies valeurs publiques VITE_SUPABASE_URL et VITE_SUPABASE_ANON_KEY doivent être ajoutées dans Vercel > Settings > Environment Variables.
- La clé service_role, les secrets SMTP, Turnstile et VAPID privés ne doivent jamais être dans GitHub ni dans les variables VITE_.
- Le SQL des migrations doit être exécuté dans Supabase SQL Editor, dans l’ordre décrit dans README_GITHUB.md / site/START-HERE.md.
